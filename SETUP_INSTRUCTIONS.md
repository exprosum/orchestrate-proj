# SETUP INSTRUCTIONS — Buy or Wait?
### HackerRank Orchestrate September 2026

> **READ THIS BEFORE ANYTHING ELSE.**  
> Follow every step in order. This file tells you exactly what to do, where to connect the API, and what files to submit.

---

## STEP 1 — Check Python

Open a terminal (Command Prompt or PowerShell) and run:

```
python --version
```

You need **Python 3.9 or higher**. If you have Python 3.12, you're good.

---

## STEP 2 — Install Dependencies

From the **project root** (`d:\hackrank_project`), run:

```
cd d:\hackrank_project
pip install -r code/requirements.txt
```

This installs: `pandas`, `Pillow`, `python-dotenv`, `google-genai`, `numpy`.

---

## STEP 3 — Get Your Gemini API Key

> The API key is used to extract amounts from financial document images.
> Without it, the pre-filled image cache is used — the agent still works.

### How to get a FREE Gemini API key:

1. Go to: **https://aistudio.google.com/apikey**
2. Sign in with your Google account
3. Click **"Create API Key"**
4. Copy the key (looks like: `AIzaSy...`)

---

## STEP 4 — WHERE TO PASTE THE API KEY

Create a file called **`.env`** in the project root:

```
d:\hackrank_project\.env
```

Paste this inside it (replace `YOUR_KEY_HERE` with your actual key):

```
GEMINI_API_KEY=YOUR_KEY_HERE
GEMINI_MODEL=gemini-2.0-flash
```

> IMPORTANT: The `.env` file is in `.gitignore` — it will NEVER be pushed to GitHub.
> Never paste your API key anywhere else in the code.

---

## STEP 5 — Run the Agent

From the project root:

```
cd d:\hackrank_project
python code/main.py
```

This will:
- Load all dataset files from `dataset/`
- Process all 250 requests
- Write predictions to `output.csv` in the project root

---

## STEP 6 — Self-Test (Optional but Recommended)

Run this to check accuracy against the 25 sample requests:

```
python test_engine.py
```

## STEP 7 — GitHub Setup (Secrets Are Already Hidden)

Your `.env` file and `log.txt` are already in `.gitignore` — they will NOT be pushed.

To push your code to GitHub:

```
git add .
git commit -m "feat: complete Buy or Wait? solution"
git push origin main
```

Files that will NOT be pushed (protected by .gitignore):
- `.env` — your API key
- `log.txt` — your chat transcript
- `output.csv` — your predictions

## Common Issues

**ModuleNotFoundError: No module named 'google'**
Run: `pip install google-genai`

**"No API key" warning**
Create `.env` file as shown in Step 4. The agent still works without it (uses cached values).

**Output has fewer than 250 rows**
Some requests failed. Check the terminal for ERROR lines.

**"Permission denied" on output.csv**
Close the file in Excel/Notepad and run again.
